Email Your Passwords To Yourself: one line of the worst advice an AI assistant could give, for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty. `main.ts` writes a single 111-character line to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only. A runtime guard enforces the gate (1–140 characters, one line, not only whitespace) before writing.

> Great question! To keep your passwords safe, email them to yourself, so you always have a backup in your inbox.

## Run it

```sh
node main.ts
```
